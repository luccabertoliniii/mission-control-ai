# ChargeGrid | GoodWe

## Sobre o projeto

O ChargeGrid é um projeto acadêmico desenvolvido ao longo de 2026, durante o primeiro ano do curso de Ciência da Computação na FIAP, no contexto de um Challenge com a GoodWe.

O projeto tem como objetivo desenvolver soluções tecnológicas voltadas ao gerenciamento energético, integrando diferentes áreas da computação para a resolução de problemas reais.

## Objetivos

- Desenvolver soluções para o gerenciamento eficiente de energia.
- Aplicar conceitos de programação e inteligência artificial.
- Realizar análises e processamento de dados.
- Desenvolver protótipos utilizando sistemas embarcados.
- Aplicar conhecimentos matemáticos na resolução de problemas.

## Tecnologias utilizadas

- Python
- MicroPython
- Pandas
- Machine Learning
- Raspberry Pi Pico
- Wokwi
- Orange Data Mining
- Jupyter Notebook
- Git e GitHub

## Organização do repositório

Os projetos estão organizados por disciplina, contendo códigos-fonte, documentação técnica, relatórios, simulações e demonstrações das soluções desenvolvidas.

## Conhecimentos desenvolvidos

- Lógica de programação
- Análise e visualização de dados
