# Mission Control AI – Monitoramento de Missões Espaciais

## Sobre o projeto

O Mission Control AI é um projeto acadêmico desenvolvido durante a Global Solution do primeiro semestre de 2026, no curso de Ciência da Computação da FIAP.

O projeto tem como objetivo explorar a aplicação de soluções computacionais no monitoramento de missões espaciais, utilizando dados simulados para analisar condições operacionais, identificar situações de risco e auxiliar na tomada de decisões.

A proposta integra diferentes áreas da computação, aplicando conceitos tecnológicos em um contexto de exploração espacial.

## Objetivos

- Monitorar informações operacionais de uma missão espacial.
- Processar e analisar dados simulados de sensores.
- Identificar situações de risco e condições anormais.
- Emitir alertas relacionados ao funcionamento da nave.
- Organizar informações para facilitar a tomada de decisões.
- Aplicar conhecimentos computacionais na resolução de problemas.

## Monitoramento operacional

Uma das soluções propostas pelo projeto consiste no monitoramento das seguintes informações:

- Temperatura da nave.
- Nível de energia.
- Status da comunicação.
- Condições operacionais da missão.

A análise dessas informações permite identificar situações que exigem atenção durante a operação.

## Sistema de alertas

| Condição | Resposta do sistema |
|---|---|
| Temperatura superior a 80 | Alerta de superaquecimento |
| Energia inferior a 20% | Economia de energia |
| Comunicação igual a 0 | Falha de comunicação |

## Funcionalidades propostas

- Inserção e simulação de dados operacionais.
- Visualização do status da missão.
- Análise automática das condições operacionais.
- Emissão de alertas.
- Consulta ao histórico de leituras.
- Interface interativa para acompanhamento da missão.
